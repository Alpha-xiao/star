# 护理记录 · 历史趋势与图表 设计说明

> 对应《项目完整性分析报告》3.1.1，配合 [护理记录历史趋势与图表_高保真设计.html](./护理记录历史趋势与图表_高保真设计.html) 使用。
> 输出人：产品经理（PM 视角）
> 更新时间：2026-07-03

---

## 1. 目标与背景

- 现状：统计页目前只能翻看单日明细，用户无法回答「宝宝这周比上周吃得多吗、睡得好吗」。
- 目标：让每天辛苦录入的数据变成「可翻阅的趋势」和「可分享的报告」，把 BabyStar 从「能用」推向「好用」。
- 核心用户任务：
  1. 快速看到本周/本月核心指标与环比。
  2. 一屏看清奶量、母乳、睡眠、排泄的变化节奏。
  3. 一键把数据带出去给医生或家人。

---

## 2. 信息架构

统计页顶部新增「日 / 周 / 月」三段视图切换，默认周视图。

| 视图 | 目的 | 主体内容 |
|---|---|---|
| 日 | 单日复盘（保留现有） | 单日明细列表 |
| 周 | 主推趋势视角 | 周报摘要 + KPI 磁贴 + 折线/柱状 + 洞察 |
| 月 | 宏观回顾 | 单指标切换 + 热力图 + 7 日移动平均 |

## 3. 页面模块拆解

### 3.1 顶部导航区

- 视图 Tab（日/周/月）：胶囊分段控件，选中态品牌橙 + 投影。
- 日期导航：左右箭头翻页 + 中间显示区间（如「6月26日 - 7月2日 · 本周」）+「今天」快捷跳回。

### 3.2 周报摘要卡（Hero）

- 品牌橙渐变 `#FFAB40 → #E65100`，白色文字。
- 三指标：总奶量、睡眠时长、排泄次数，各带上周环比徽章（↑ 绿 / ↓ 弱化）。
- 目的：进入页面 1 秒内给结论。

### 3.3 KPI 磁贴（2×2）

- 日均奶量、母乳时长、日均睡眠、日均喂奶次数。
- 图标底色使用护理类型专属色（奶粉橙、母乳粉红、睡眠紫、拉尿蓝）。
- 底部小字显示环比或参考区间。

### 3.4 单指标图表卡

- 奶量趋势：ECharts smooth line + 面积渐变，本期实线 + 上周虚线对比。
- 母乳时长：可切到同一图上的第二个 y 轴或独立单指标视图。
- 排泄次数：拉尿/拉屎双色堆叠柱。
- 睡眠：独立入口卡（跳转到「睡眠趋势」专项页），展示日均、单次时长、夜醒、清醒窗口。
- 图表统一 220px 高、卡片 20px 圆角、卡片阴影 `0 6px 18px rgba(80,55,30,0.1)`。

### 3.5 洞察卡

- 每周 3 条要点，自动生成模板：
  - 「奶量平稳上升，符合月龄参考区间」
  - 「周三夜奶次数较多（3 次），建议关注」
  - 「白天睡眠占比 42%，作息接近规律」
- 目的：帮用户「读懂」数据，减少焦虑，同时预留后续 AI 建议 (P2 3.3.2)。

### 3.6 月视图专有：热力图

- 7 列日历网格，颜色 5 档（0 / 低 / 中低 / 中高 / 高）。
- 阈值取最近 30 天分位数（P20/P40/P60/P80），避免绝对值偏差。
- 当天用品牌橙 outline 标记；空白日缺数据用中性灰。
- 点击某格进入日视图详情，与现有页面串联。

### 3.7 空状态与引导

- 数据不足条件：区间内有效记录 < 3 天。
- 展示空状态卡：图标 + 「本周还没有足够数据」 + 「去记录一条」CTA。
- 同时保留「最近的记录」列表，引导用户「补录」，与 P1 3.2.2 记录回填打通。

### 3.8 导出/分享

- 底部或右上角固定入口：「导出 CSV」+「分享长图」。
- 与 3.1.2 数据导出复用能力。

## 4. 数据与接口

- 复用后端已有 `GET /stats/range?from&to&babyId`，前端本地聚合为周/月序列。
- 新增前端 store `useTrendStore`：
  - 状态：`weekly[babyId]`、`monthly[babyId]`、`lastFetchedAt`
  - 方法：`loadWeek(range)`、`loadMonth(month)`、`invalidate()`
  - 切换宝宝 / 用户退出 / 权限变化时 `invalidate()`。
- 洞察卡逻辑：前端根据聚合结果按规则匹配文案模板；后期可迁移到后端接口 `/stats/insights`。

---

## 5. 交互细节

- Tab / 日期 / 指标切换均 200ms 内响应，加载中显示骨架。
- 图表点击某点，联动周报摘要 KPI 高亮，并可点击直接跳到日视图。
- 深色模式：卡片 `#1f1a15`，图表主色不变，网格线 `rgba(255,255,255,0.08)`。
- 无网络：使用最近一次缓存 + 顶部提示条「离线数据，可能不是最新」。
- 权限：viewer 也可以查看，但导出/分享按钮显示禁用态并有提示。

## 9. 里程碑拆分建议（研发交付）

- M1（3 天）：视图 Tab + 日期导航 + KPI 磁贴 + 奶量折线。
- M2（2 天）：排泄柱状 + 母乳时长 + 周报摘要卡。

合计 ~9 人日，与项目完整性报告中 3.1.1 的「5-7 天」范围相符（不含数据导出 3.1.2 的额外工作）。

## 10. 依赖与风险

- **依赖**：3.1.2 数据导出会挂在同一入口，建议同期规划。
- **数据风险**：小样本时环比可能大幅波动，需要在文案上留白（例如「上周记录不足，暂不对比」）。
- **性能**：月视图一次拉 30 天数据，需在 `/stats/range` 侧确认最大跨度（后端已知问题：跨度无上限，建议限制为 92 天并加缓存）。
