## 宝宝档案页设计规范

> 宝宝档案分为两种模式：**创建模式**（首次使用时引导填写）和**查看模式**（创建后查看/编辑）。

---

### 一、页面路由与入口

```
路由: /profile（查看模式）/ /profile/create（创建模式）

入口位置:
  - 首页右上角头像图标 → /profile
  - 首次打开 App 自动跳转 → /profile/create（无宝宝档案时）
  - 设置页 → /profile
```

#### 2.3 表单校验

| 字段 | 必填 | 校验规则 |
|------|------|---------|
| 宝宝昵称 | ✅ | 1-10个字符，不允许纯空格 |
| 出生日期 | ✅ | 不晚于今天，不早于2年前 |
| 性别 | ✅ | 必选 |
| 出生体重 | ❌ | 0.5-6.0 kg，精度 0.01 |
| 出生身高 | ❌ | 30-60 cm，精度 0.1 |

#### 2.4 提交后逻辑

```
1. 调用 POST /api/babies 创建宝宝档案
2. 保存到 Pinia store + localStorage
3. 跳转首页 /
4. showToast("宝宝档案创建成功")
5. 首页右上角头像替换为宝宝头像/首字母
```

#### 3.3 编辑模式

点击右上角 ✏️ 图标进入编辑模式：

```
交互方式: 在当前页面原地切换为表单状态（不跳页）
  - 头像变为可点击（加相机图标叠层）
  - 昵称变为输入框
  - 出生日期变为可选择
  - 性别变为可切换
  - 体重/身高变为可输入
  - 血型显示下拉选择（A/B/AB/O/未知）

顶部导航变化:
  - 左侧 ✕ (取消) 替换 ← (返回)
  - 右侧 "保存" 替换 ✏️ (编辑)
  - 保存按钮: 16px bold #E65100

保存后:
  1. 调用 PUT /api/babies/:id 更新
  2. 更新 Pinia store
  3. 切回查看模式
  4. showToast("档案已更新")
```

### 四、数据模型

```typescript
// types/baby.ts

interface Baby {
  id: string
  name: string              // 宝宝昵称
  birthday: string          // 出生日期 YYYY-MM-DD
  gender: 'male' | 'female'
  birthWeight?: number      // kg
  birthHeight?: number      // cm
  bloodType?: 'A' | 'B' | 'AB' | 'O' | 'unknown'
  avatarUrl?: string        // 头像 URL (可选)
  createdAt: string
  updatedAt: string
}

// 计算属性 (前端)
const ageInDays = computed(() => {
  const birth = new Date(baby.birthday)
  const now = new Date()
  return Math.floor((now.getTime() - birth.getTime()) / 86400000)
})

const ageText = computed(() => {
  const days = ageInDays.value
  if (days < 30) return `${days}天`
  const months = Math.floor(days / 30)
  const remainDays = days % 30
  if (months < 12) return remainDays > 0 ? `${months}个月${remainDays}天` : `${months}个月`
  const years = Math.floor(months / 12)
  const remainMonths = months % 12
  return remainMonths > 0 ? `${years}岁${remainMonths}个月` : `${years}岁`
})
```

### 五、API 接口

```
POST   /api/babies          创建宝宝档案
GET    /api/babies/:id      获取宝宝信息
PUT    /api/babies/:id      更新宝宝信息
DELETE /api/babies/:id      删除宝宝档案 (含二次确认)
POST   /api/babies/:id/avatar  上传头像 (multipart/form-data)
```

### 七、与现有页面的集成点

| 页面 | 集成方式 |
|------|---------|
| **App.vue** | `router.beforeEach` 检查 `babyStore.hasProfile`，无档案时重定向到 `/profile/create` |
| **Home.vue** | 右上角头像从 `User` 图标改为宝宝头像（有档案时）或首字母 |
| **Stats.vue** | 日期旁的"今天"按钮旁可增加宝宝月龄显示 |
