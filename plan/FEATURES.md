## 📋 功能详情

### 1. 记录首页 (Home)

#### 大按钮网格

- 2x2 布局，4个大尺寸按钮
- 每个按钮配有 emoji 图标和文字
- 点击反馈效果（缩放+透明度）
- 颜色区分不同功能

#### 记录交互

- **拉屎**：ActionSheet 弹出，4个预设选项
  - 黄色糊状
  - 绿色稀便
  - 有奶瓣
  - 其他
- **拉尿**：ActionSheet 弹出，3个预设选项
  - 量多
  - 量少
  - 换尿布
- **母乳喂养**：Dialog 弹窗，2项输入
  - 喂养位置：左侧/右侧/双侧
  - 时长：1-60分钟
- **奶粉喂养**：Dialog 弹窗，1项输入
  - 奶量：10-300ml，步长10ml

#### 撤销功能

- 右上角撤销按钮
- 二次确认对话框
- 支持撤销最后一条记录

### 2. 统计页面 (Stats)

#### 统计卡片

- 4个卡片组成 2x2 网格
- 显示当日各项指标总量
- 顶部边框颜色区分类型
- 单位清晰标注

#### 统计项

- 🍼 奶粉总量（ml）
- 🤱 母乳时长（分钟）
- 💩 拉屎次数（次）
- 💧 拉尿次数（次）

#### 其他功能

- 当前日期显示（含星期）
- 空状态提示
- 腾讯文档跳转按钮

### 3. 数据管理

#### 本地存储

- 当日记录：`localStorage.today_records`
- 待同步记录：`localStorage.pending_records`

#### 同步机制

- 记录时立即尝试提交
- 失败自动暂存
- 应用启动时检查并同步
- 网络恢复时自动同步
- 同步成功后清除暂存

### 4. 导航系统

#### 底部 TabBar

- 2个导航项
- 记录页（首页）
- 统计页
- 路由绑定，高亮状态

## 🔧 技术实现

### 状态管理 (Pinia)

```typescript
useRecordStore {
  todayRecords: BabyRecord[]
  addRecord(record)
  undoLastRecord()
}
```

### 数据类型

```typescript
BabyRecord {
  event_type: '拉屎' | '拉尿' | '母乳喂养' | '奶粉喂养'
  timestamp: string
  duration?: number
  side?: string
  amount?: number
  note?: string
}
```

### API 方法

- `submitRecord(record)` → Promise<boolean>
- `syncPendingRecords()` → Promise<void>
