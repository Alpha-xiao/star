设计说明（3.1.1 历史趋势与图表）

1. 信息架构

统计页顶部新增「日 / 周 / 月」三段视图切换。默认进入周视图，因为周粒度最能回答父母最常问的问题：「这周比上周吃得多吗？睡得好吗？」

  • 日视图 — 保留现有单日明细，用于回顾具体某天。
  • 周视图 — 主推的趋势视角，含周报摘要 + 单指标折线/柱状图 + 洞察卡。
  • 月视图 — 大周期回顾，采用「热力图 + 7 日移动平均」呈现宏观趋势。

2. 组件模块

  • 周报摘要卡 ：品牌橙渐变，突出总奶量、睡眠时长、排泄次数三项与上周环比，第一时间给出结论。
  • KPI 磁贴 ：日均奶量 / 母乳时长 / 日均睡眠 / 日均喂奶次数，配色沿用护理类型专属色，便于快速定位指标。
  • 趋势折线 ：ECharts smooth line + AreaStyle，主线为本期，浅灰虚线为对比期（上周/上月），支持点击定位到当日。
  • 排泄柱状 ：拉尿/拉屎双色堆叠柱状，视图内切换单指标下钻。
  • 月度热力图 ：7×N 网格，颜色阶梯代表当日总量；点击某格进入日视图详情。
  • 洞察卡 ：每周自动生成 3 条要点，覆盖趋势、异常、作息节律，弱化数据焦虑感。
  • 导出/分享 ：接入 3.1.2 数据导出，趋势页顶层直达 CSV 与长图分享。

3. 数据与接口

  • 复用后端已有 GET /stats/range?from&to&babyId ，前端本地聚合为周/月序列。
  • 新增前端 store useTrendStore ：缓存周/月序列，切换视图/日期区间时避免重复请求。
  • 热力图使用「日总量分级」，等级建议 5 档（0 / 低 / 中低 / 中高 / 高），阈值按最近 30 天分位数动态计算。

4. 交互与状态

  • 顶部视图 Tab、日期导航、单指标切换三层组合，避免多层跳转。
  • 图表滑动/长按显示 tooltip，同时高亮周报摘要中对应 KPI。
  • 数据不足（< 3 天）显示空状态卡与「去记录一条」CTA，同时保留「最近的记录」引导补录，配合 3.2.2 记录回填。
  • 无网络时降级为本地缓存数据 + 顶部小提示，与离线暂存机制保持一致。
  • 切换宝宝或角色变化时，趋势缓存需清空并重新拉取，避免跨宝宝串数据。

5. 视觉与主题

  • 沿用项目暖米色背景 ( #FAF5F0 ) + 品牌橙渐变 + 卡片 20px 圆角 + 卡片阴影 0 6px 18px rgba(80,55,30,0.1) 。
  • 护理类型专属色保持一致：奶粉橙、母乳粉红、拉尿蓝、拉屎棕、睡眠紫。
  • 深色模式下：卡片改为 #1f1a15 ，图表主色不变，网格线转为 rgba(255,255,255,0.08) 。

6. 埋点与运营

  • trend_view_tab_click ：视图切换。
  • trend_range_change ：日期区间切换（周/月/自定义）。
  • trend_metric_switch ：指标切换（月视图）。
  • trend_export_click ：导出/分享入口点击。
  • trend_empty_cta_click ：空状态 CTA 点击。
