## 记录明细交互优化 — 设计规范与 Trae 实施 Prompt

> 解决当前 stats.vue 记录明细区域在手机上"太紧凑"的问题。

---

### 一、当前问题分析

| 问题 | 现状 | 影响 |
|------|------|------|
| 触摸目标太小 | 编辑按钮 20px、撤销按钮 20px | 远低于 Apple HIG 推荐的 44px 最小触摸目标，容易误触 |
| 单行信息过载 | 色点+类型+详情+时间+编辑+撤销 全挤在一行 | 375px 屏幕上文字被截断，右侧按钮拥挤 |
| 操作按钮辨识度低 | 铅笔图标=编辑、右箭头=撤销 | 图标含义不直观，撤销用箭头容易和"展开/跳转"混淆 |
| 列表高度受限 | `max-height: calc(100vh - 430px)` | 记录多时需要频繁滚动，且高度计算不灵活 |
| 缺少触觉反馈 | 没有滑动操作，所有操作都是小按钮点击 | 不符合移动端操作直觉 |

---

### 二、优化方案

#### 核心思路：把操作从"可见小按钮"改为"左滑露出"

```
┌─────────────────────────────────────────────┐
│ ┃ 记录明细                           4条     │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │  ● 奶粉喂养 60ml              10:42   │  │  Line 1: 类型+详情+时间
│  │    妈妈记录                            │  │  Line 2: 记录人标签
│  ├───────────────────────────────────────┤  │
│  │  ● 拉尿 量少                  11:15   │  │
│  │    爸爸记录                            │  │
│  ├───────────────────────────────────────┤  │
│  │  ● 拉屎 泡沫便                13:30   │  │
│  │    妈妈记录                            │  │
│  ├───────────────────────────────────────┤  │
│  │  ● 母乳喂养 左侧·15min        14:20   │  │
│  │    奶奶记录                            │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘

                    左滑某一条 ↓

┌─────────────────────────────────────────────┐
│  ● 奶粉喂养 60ml        10:42  ┌─────┬─────┐│
│    妈妈记录                     │ 编辑 │ 撤销 ││  ← 滑出操作按钮
│                                │     │     ││    各 64px 宽
└────────────────────────────────┴─────┴─────┘│
```

#### 改动要点

1. **列表项改为两行布局**：第一行放"色点 + 类型 + 详情 + 时间"，第二行放"记录人标签"（仅多人协作时显示）。行高从 `1rem padding` 增至 `14px`，视觉上更透气。

2. **移除可见的编辑/撤销小按钮**：整条记录可点击进入编辑弹窗；撤销操作改为左滑露出（使用 Vant 内置的 `van-swipe-cell` 组件）。

3. **左滑操作按钮**：
   - 编辑按钮：64px 宽，蓝色背景 (#1565C0)，白色文字"编辑"
   - 撤销按钮：64px 宽，红色背景 (#E53935)，白色文字"撤销"
   - 共 128px 的操作区，符合 44px 触摸目标要求

4. **列表高度改为自适应**：移除 `max-height` 限制，让列表自然撑开，整个统计页可以滚动。

5. **记录人标签**：只在家庭协作模式（`familyStore.hasMembers`）时显示第二行，单人使用时只显示一行，保持简洁。

### 三、组件规格

#### 3.1 记录列表容器

```css
/* 改造 .record-list */
.record-list {
  border-radius: 20px;          /* var(--radius-large) */
  background: #fff;
  padding: 4px 16px;            /* 上下 4px（第一项自带 14px），左右 16px */
  box-shadow: var(--card-shadow);
  /* 移除 max-height，让页面自然滚动 */
}
```

#### 3.2 记录列表项（两行布局）

```
结构:
  van-swipe-cell (包裹整条记录)
    ├── 左侧内容 (正常态)
    │   ├── Line 1: 色点(10px) + 事件类型(15px 600) + 详情(14px #999) ←→ 时间(13px #999)
    │   └── Line 2: 记录人标签 (仅 hasMembers 时渲染)
    │
    └── 右侧操作 (滑动露出)
        ├── 编辑按钮: 64×auto, bg #1565C0, 白色文字 14px 600
        └── 撤销按钮: 64×auto, bg #E53935, 白色文字 14px 600

尺寸:
  行内 padding: 14px 0
  色点: 10×10px 圆形, margin-right 10px
  事件类型: 15px font-weight 600, color var(--text-primary)
  详情文字: 14px font-weight 400, color var(--text-tertiary), margin-left 4px
  时间: 13px color var(--text-tertiary), 自动右对齐 (ml-auto)
  Line 2 缩进: margin-left 20px (对齐色点右侧的文字起始位置)

记录人标签:
  display: inline-block
  padding: 2px 8px
  border-radius: 8px
  font-size: 11px, font-weight 500
  颜色: 根据记录人角色映射
    自己: bg #FFEBD6, text #E65100
    其他: bg #F0F0F0, text #666
  margin-top: 4px

分割线:
  border-bottom: 1px solid #F5F5F5
  最后一条无分割线
```

#### 3.3 左滑操作按钮

```html
<!-- 使用 Vant SwipeCell -->
<van-swipe-cell>
  <div class="record-item" @click="openEditDialog(record)">
    <!-- 正常态内容 -->
  </div>
  <template #right>
    <button class="swipe-btn bg-[#1565C0]" @click="openEditDialog(record)">
      编辑
    </button>
    <button class="swipe-btn bg-[#E53935]" @click="onUndoRecord(record)">
      撤销
    </button>
  </template>
</van-swipe-cell>
```

```css
.swipe-btn {
  display: flex;
  align-items: center;
  justify-content: center;
  width: 64px;
  height: 100%;
  color: #fff;
  font-size: 14px;
  font-weight: 600;
  border: none;
}
```

#### 3.4 列表头部

```
标题行:
  左侧: 橙色竖线 (3×14px, bg var(--brand-secondary)) + "记录明细" 16px 600
  右侧: "{N}条" 12px var(--text-tertiary)
  margin-bottom: 12px
```

### 四、Trae 实施 Prompt

把以下 prompt 直接粘贴给 Trae 执行：

```
请优化 src/views/stats.vue 中"记录明细"区域的移动端交互体验。

当前问题：
- 每条记录在一行内塞了色点+类型+详情+时间+编辑按钮+撤销按钮，375px 屏幕上非常拥挤
- 编辑按钮和撤销按钮只有 20px，触摸目标太小
- 撤销按钮用 ArrowRight 图标，含义不直观

改造要求：

1. 导入 Vant 的 SwipeCell 组件（van-swipe-cell），以及移除 lucide 的 ArrowRight 和 Pencil 图标导入（不再需要）。

2. 将每条记录用 van-swipe-cell 包裹，实现左滑露出操作按钮：
   - 右侧模板(#right)放两个按钮：
     · "编辑"按钮：64px 宽，bg #1565C0，白色 14px 600，点击调用 openEditDialog(record)
     · "撤销"按钮：64px 宽，bg #E53935，白色 14px 600，点击调用 onUndoRecord(record)
   - 按钮样式类 .swipe-btn:
     display: flex; align-items: center; justify-content: center;
     width: 64px; height: 100%; color: #fff; font-size: 14px; font-weight: 600; border: none;

3. 列表项内容改为两行布局（移除右侧的小按钮组）：

   Line 1 (flex, items-center):
     - 色点: 10×10px 圆形，用 getRecordDotClass(record) 获取颜色类
     - 事件类型: 15px font-semibold, color var(--text-primary)
     - 详情文字: 14px, color var(--text-tertiary), ml-1
     - 时间: 13px, color var(--text-tertiary), ml-auto (自动推到右边)

   Line 2 (仅在 familyStore.hasMembers 且 record.recorder?.nickname 时显示):
     - ml-5 (对齐色点右侧文字), mt-1
     - 标签: inline span, padding 2px 8px, 圆角 8px
     - 如果 recorder.userId 等于当前用户 → bg #FFEBD6, text #E65100, 内容 "{nickname}"
     - 否则 → bg #F0F0F0, text #666, 内容 "{nickname}"
     - font-size 11px, font-weight 500

4. 整条记录项可点击（@click="openEditDialog(record)"），cursor pointer。

5. 列表容器改造：
   - 移除 max-height 限制（删掉 style.css 中 .record-list 的 max-height 和 overflow-y）
   - padding 改为 4px 16px
   
6. 列表头部改造：
   - 标题行右侧新增记录条数: "{records.length}条", 12px, var(--text-tertiary)

7. 在 style.css 中：
   - .record-item: padding 改为 14px 0（原 1rem）
   - .record-item 的 grid-template-columns 改为 flex 布局（不再是 grid）
   - 新增 .swipe-btn 样式
   - .btn-undo 类保留（用于撤销 loading 态），但不再在模板中使用（SwipeCell 按钮替代）

8. 确保撤销操作仍然弹出确认对话框（showConfirmDialog），SwipeCell 的撤销按钮只是替代了原来的小箭头按钮的入口，逻辑不变。

9. 完成后在 375px 和 430px 宽度下检查：
   - 每条记录显示完整，文字不截断
   - 左滑操作流畅，按钮高度与记录行等高
   - 点击记录项可正常打开编辑弹窗
   - 多人协作时第二行标签显示正确

参考: plan/记录明细优化设计规范.md
```

### 五、改造前后对比

| 维度 | 改造前 | 改造后 |
|------|--------|--------|
| 布局 | 单行 grid (14px 1fr auto) | 两行 flex，Line1=信息 Line2=记录人 |
| 操作入口 | 20px 铅笔按钮 + 20px 箭头按钮 | 左滑露出 64px 编辑 + 64px 撤销 |
| 触摸目标 | 20px (不达标) | 64px (远超 44px 最低要求) |
| 编辑方式 | 点小铅笔 / 点整行 | 点整行 / 左滑点编辑 |
| 撤销方式 | 点小箭头 + 确认弹窗 | 左滑点"撤销" + 确认弹窗 |
| 列表高度 | 固定 max-height 截断 | 自然撑开，整页可滚动 |
| 记录人信息 | 有成员时挤在第一行下面 | 独立第二行，带彩色标签 |
| 视觉噪音 | 每条记录都有 2 个小图标按钮 | 干净的信息列表，操作按需露出 |
