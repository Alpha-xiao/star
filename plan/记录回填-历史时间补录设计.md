# BabyStar 历史时间补录（记录回填）— 高保真设计

> 需求来源：`plan/项目完整性分析报告.md` §3.2.2 记录回填（历史时间补录）
> 目标：让奶粉/母乳/拉尿/拉屎 也支持"选择过去时间补录"，与睡眠已有的"手动记录"体验对齐。
> 输出范围：交互流程、视觉高保真、组件设计、状态管理、后端契约、埋点、验收标准。

---

## 一、目标与非目标

### 1.1 目标

| 目标 | 说明 |
|------|------|
| 五类记录（奶粉/母乳/拉尿/拉屎/睡眠）都可补录 | 睡眠已有手动记录，本次统一其余 4 类的入口和交互 |
| 单手操作、路径最短 | 常规「立即记录」不改，补录作为二级入口 |
| 时间校验合理 | 不允许未来时间，不允许早于宝宝出生日 |
| 可视化区分补录 | 列表明细一眼能看出这条是补录，避免和实时记录混淆 |
| 不牺牲现有稳定性 | 复用现有 `clientId + submitRecord` 幂等和离线队列 |

### 1.2 非目标

- 本次不做"跨天大批量补录"的批量导入工具（属于 P3 数据迁移，另做）
- 不改变现有睡眠手动记录的入口位置，只统一命名与视觉
- 不改动统计接口结构，仅按 `happenedAt` 归日

## 三、用户流程

### 3.1 主流程：从首页补录奶粉

```
用户
 │  长按「奶粉」按钮 400ms
 ▼
Home.vue —— haptic 轻震动（vibrate 15ms）
 │  打开 <BackfillDialog type="formula" />
 ▼
补录奶粉弹窗
 │  ① 选择「发生时间」：日期 + 时分
 │  ② 步进器：奶量 (10–300 ml)
 │  ③ 备注（选填）
 │  ④ 「保存」
 ▼
校验
 │  · happenedAt ≤ now()
 │  · happenedAt ≥ baby.birthday 00:00
 │  · 未来 / 早于出生 → 内联错误 + 禁用保存
 ▼
records.addRecord + submitRecord({ isBackfill:true })
 │
 ├─ 成功：Toast「已补录 10:24 奶粉 60ml」+ 关闭弹窗
 └─ 失败：进入 pending_records，Toast「已暂存本地」
```

### 3.2 分支：统计页补录

```
Stats.vue（选中 6/15）
 │  点击 顶部「＋补录」
 ▼
选择记录类型
 │  底部弹层：奶粉 / 母乳 / 拉尿 / 拉屎 / 睡眠
 ▼
补录 <类型> 弹窗
 │  默认日期 = 当前查看日期
 │  默认时分 = 现在时分
 ▼
保存后：自动 refresh 当前日期的 stats + records
```

### 3.3 分支：睡眠补录

沿用现有 `showManualSleepDialog`，仅：
- 按钮文案「手动记录 → 补录睡眠」
- 内部字段命名和其余四类保持一致（`happenedAt / endedAt`）
- 顶部标题「补录睡眠」

### 5.2 BackfillDialog Props / Emits

```ts
interface BackfillDialogProps {
  visible: boolean;
  type: 'formula' | 'breast' | 'urine' | 'stool' | 'sleep';
  babyBirthday?: string | null; // 用于校验最小时间
  initialDate?: string;         // YYYY-MM-DD，默认今天
}

interface BackfillDialogEmits {
  (e: 'update:visible', v: boolean): void;
  (e: 'submitted', record: BabyRecord): void;
}
```

内部通过 `<slot name="fields">` 让四种类型各自渲染字段（奶粉/母乳/拉尿/拉屎/睡眠共用时间和备注区）。

### 5.3 时间控件 BackfillTimeField

- 内部维护 `date: YYYY-MM-DD` 和 `time: HH:mm`。
- 交互：点击日期打开 `van-date-picker`（min = birthday，max = 今日）；点击时间打开 `van-time-picker`。
- 「现在」按钮：把 date/time 拉到当前值。
- 校验：`combine(date, time) <= Date.now()`；`combine(date, time) >= birthday 00:00`。

### 5.4 校验规则

| 规则 | 提示 | 触发时机 |
|------|------|----------|
| 时间不可为未来 | ⚠ 补录不能选择未来时间 | 时间变更时同步校验 |
| 时间不早于宝宝出生 | ⚠ 该时间早于宝宝出生日 | 同上 |
| 睡眠补录：入睡 + 时长 > 当前 | ⚠ 睡眠尚未结束，请稍后再补录 | 步进器/时间变更 |
| 奶量、时长范围超限 | 由 `van-stepper` 内置约束 | 输入时 |
| 备注长度 ≤ 100 | 由 `van-field maxlength` | 输入时 |

校验失败时保存按钮 `disabled=true`；无内联错误优先展示，避免误触后才提示。

## 六、状态与数据流

```
BackfillDialog
    │  submitBackfill()
    ▼
records store
  addBackfillRecord(record: BabyRecord) {
    record.clientId ??= crypto.randomUUID();
    record.source = 'backfill';       // 新增语义标记
    todayRecords.unshift(record);
    saveToLocal();
    submitRecord(record);             // 复用现有幂等 + 离线队列
  }
```

- **不新增**独立的 pending 队列，沿用 `pending_records`，保证离线补录也能自动同步。
- 首页计时器不受补录影响：`lastFeedRecord` 计算已按 `timestamp` 排序，补录一条 09:00 的记录不会覆盖 10:30 的最新一条。

## 七、后端契约（不改变现有 API 形态）

| 变更 | 说明 |
|------|------|
| `POST /api/records` | 请求体新增可选字段 `source: 'pwa' \| 'backfill'`，默认 `'pwa'` |
| `POST /api/records/batch` | 同上，透传 source |
| 校验 | 后端仍校验 `happenedAt <= now + 30s`；补录时也不允许未来 |
| 数据库 | `care_records.source` 已有该列（枚举），本次仅增加 `'backfill'` 枚举值；不需要迁移历史数据 |

> 若不希望引入枚举变更，可以退化为在 `note` 前加 `[补录]` 前缀。但推荐加 `source='backfill'`，与统计/审计需求兼容。

## 八、埋点

| 事件 | 触发时机 | 关键属性 |
|------|----------|----------|
| `backfill_entry_open` | 打开补录弹窗 | `entry: home_longpress \| home_clock \| stats_button \| sleep_card`, `type` |
| `backfill_submit_success` | 保存成功 | `type`, `delta_minutes = now - happenedAt` |
| `backfill_submit_fail` | 保存失败 | `type`, `reason` |
| `backfill_cancel` | 关闭弹窗未保存 | `type`, `dwell_ms` |

`delta_minutes` 用于事后分析：多数补录发生在多久之前，帮助未来做"5 分钟内一键补录"优化。

## 九、可访问性与国际化

- 弹窗打开时自动聚焦第一个可编辑字段。
- 时间/日期字段暴露 `aria-label`：`发生时间-日期` / `发生时间-时分`。
- 深色模式：所有色值均引用 `--brand-primary / --text-primary / --surface-pressed`，无写死颜色。
- 文案统一收口到 `src/locales/backfill.ts`，未来做多语言时可整体替换。

## 十、异常与降级

| 异常 | 表现 | 处理 |
|------|------|------|
| 网络离线 | 直接进入 `pending_records` | Toast「已暂存本地，联网后自动同步」 |
| 后端 400（未来时间） | 展示后端错误信息 | 弹窗保持打开，用户可修改 |
| 后端 403（无权限记录） | Toast「只读成员无法补录」 | 关闭弹窗，跳回列表 |
| 用户切换宝宝 | 关闭弹窗并丢弃当前草稿 | 避免把 A 宝宝的补录记到 B 宝宝身上 |
